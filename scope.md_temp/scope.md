# ResearchOS — Scope Document

## Project Goal
Build an AI system that reads research paper PDFs, extracts key
information, and compares multiple papers side by side.

## In Scope (Phase 1)
- Upload 1–5 PDF research papers at a time
- Extract 8 structured parameters per paper
- Generate a per-paper structured summary
- Generate a comparison table across 2–5 papers
- Basic web dashboard (upload, view summary, view comparison)

## Out of Scope (Phase 1)
- User accounts / authentication
- Multi-language paper support
- Mobile app
- Payment / subscription features
- Real-time collaborative editing

## The 8 Extracted Parameters
1. Research Problem
2. Method Used
3. Dataset
4. Algorithm
5. Results
6. Advantage
7. Limitation
8. Future Scope
